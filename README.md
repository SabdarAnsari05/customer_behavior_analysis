# 📊 End-to-End Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end data analytics workflow, from raw data to actionable business insights. It covers data loading, exploratory data analysis (EDA), data cleaning, SQL analysis, interactive dashboard development, and report presentation.

The goal is to transform raw data into meaningful insights that support data-driven decision-making.

## 🎯 Project Objectives

- Load and explore the dataset using Python.
- Perform EDA to identify trends, patterns, and anomalies.
- Clean and preprocess data to improve data quality.
- Execute SQL queries in MySQL Workbench to answer business questions.
- Build an interactive Power BI dashboard.
- Prepare a detailed analytical report and presentation using Gamma.

## 📁 Dataset

- **Dataset Name:** `customer_shopping_behavior.csv`
- **Source:** https://github.com/SabdarAnsari05/customer_behavior_analysis/blob/main/customer_shopping_behavior.csv
- **Format:** CSV / Excel
- **Description:** This dataset contains customer shopping and purchasing information, including customer demographics, product categories, purchase amounts, discounts, payment methods, shopping frequency, and customer reviews. It can be used to analyze customer purchasing patterns, spending behavior, product preferences, and shopping trends.

## 🔄 Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas.
- Examined the dataset structure, dimensions, and data types.
- Reviewed initial records to understand the available fields.

### 2. Exploratory Data Analysis (EDA)
- Analyzed data distributions and summary statistics.
- Identified trends, patterns, and relationships between variables.
- Used visualizations to understand key metrics and outliers.

### 3. Data Cleaning
- Handled missing and duplicate values.
- Corrected data types and inconsistent formats.
- Checked data quality and prepared the dataset for further analysis.

### 4. SQL Analysis — MySQL Workbench
- Loaded the cleaned data into MySQL.
- Wrote SQL queries to answer relevant business questions.
- Used filtering, aggregation, joins, subqueries, and other SQL techniques where applicable.
- Extracted insights to support business analysis.

### 5. Power BI Dashboard
- Connected the cleaned dataset to Power BI.
- Created measures and KPIs as required.
- Designed interactive visualizations, charts, and slicers.
- Developed a dashboard to communicate key findings clearly.

### 6. Analytical Report
- Documented the project methodology and analysis.
- Summarized key findings and business insights.
- Presented recommendations based on the results.

### 7. Presentation Using Gamma
- Created a professional presentation summarizing the project.
- Highlighted the business problem, methodology, key insights, and recommendations.
- Organized the findings into a clear, presentation-ready format.

## ⚙️ How to Run

### Prerequisites
- Python 3.x
- Jupyter Notebook
- MySQL Server and MySQL Workbench
- Microsoft Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/SabdarAnsari05/customer_behavior_analysis.git
cd dcustomer_behavior_analysis
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

If `requirements.txt` is not available, install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 3: Run Python Analysis
1. Open Jupyter Notebook.
2. Navigate to `notebooks/eda_and_data_cleaning.ipynb`.
3. Update the dataset path if necessary.
4. Run the cells to perform EDA and data cleaning.

### Step 4: Execute SQL Queries
1. Open MySQL Workbench.
2. Connect to your MySQL database.
3. Import the cleaned dataset into the appropriate table.
4. Open and execute `sql/analysis_queries.sql`.

### Step 5: Explore the Dashboard
1. Open `dashboard/dashboard.pbix` in Power BI Desktop.
2. Update the data source if required.
3. Refresh the data and explore the dashboard.

### Step 6: Review the Deliverables
- Open the analytical report in the `reports/` folder.
- Review the project presentation in the `presentation/` folder.
